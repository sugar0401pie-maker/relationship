## 3. 그림 규칙 (`result_flow.report_images`)

### 4쪽 — 두 캐릭터가 함께 나오는 그림
1. 관계 그림 441장 중 `{내 유형}→{애칭 유형}`이 있으면 그것
2. 없으면 반대 방향 `{애칭 유형}→{내 유형}`
3. 없으면 두 캐릭터가 함께 나오는 승인된 다른 그림
4. 그것도 없으면 두 유형의 소개컷을 나란히 놓는 대체 레이아웃

**시안의 4쪽 그림은 임시입니다.** 문어→혹등고래(#351)와 혹등고래→문어(#311)는 아직 생성 전이라, 두 캐릭터가 함께 나오는 유일한 그림인 타로 화면용 그림(`07-reveal-b`)을 넣었습니다. 타로 카드가 보이므로 #351이 나오면 바꿉니다.

### 5~10쪽 — 두 유형 중 하나가 나오는 그림, 무작위
- 묶음: 두 유형 중 하나가 나오는 관계 그림(다른 캐릭터와 함께여도 됨) + 두 유형의 소개컷 3장씩
- 한 번 볼 때 같은 그림 중복 없음. 실서비스는 결과 번호를 시드로 섞어 새로 고침해도 같은 그림이 나오게 합니다.
- 빼는 것: 타로·사주 화면용 그림, 글자가 들어간 그림, 검수 중간본
- 문어·혹등고래 묶음: 관계 그림 34장(혹등고래 20, 문어 14) + 소개컷 6장 = 40장 (`assets/출처.csv`)

### 그림 목록 `character_image_manifest.json`
- `types`: 21유형별 원본 레퍼런스, 소개컷 3장, 단독 포즈 3장, 등장하는 관계 그림 번호
- `pairs`: 441장 각각 `pair_id`, 이야기 제목, 상태(done 300 / pending 141), 피드·스토리 파일 경로
- 경로는 Codex 폴더 기준. 올릴 때 가로 560~760px JPEG로 줄입니다.
- 관계 그림 생성이 이어지면 이 파일을 다시 만듭니다(같은 규칙).

## 6. v2.5 추가 (2026-11-25) — 연인과 함께하는 작심삼일 · 유형 뿌리

- **9쪽 아래 「{애칭|과} 함께하는 작심삼일」**: 고리(loopKey)로 `couple_plans.loops`의 가족을 고르고, `couple_activities.families[가족].steps`의 2일차·1주일·1달을 보여 줍니다. 지친 날 2일차는 2일차 아래 회색 한 줄. 1일차는 내 유형 「오늘」 카드, 3일차는 「어제 {애칭|과} 해 본 「2일차 제목」 돌아보기」 + `reflect_questions[내 유형][0]`.

- **이벤트 추가**: `plan_step_view(day)` · `plan_step_done(code)` · `sowella_nudge_open(day)`.
