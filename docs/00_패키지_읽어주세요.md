## 우선순위

충돌하면 **마스터 스펙 > 데이터 JSON > 엑셀 통합본 > 디저트 테스트 자료** 순서.
디저트 테스트 자료는 회원가입·로그인·결제·디자인 시스템·공유 시트 부분만 참고합니다. 문항·유형·채점은 디저트 테스트 것을 쓰지 않습니다.
