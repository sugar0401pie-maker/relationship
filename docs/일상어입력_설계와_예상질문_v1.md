# 강에 사는 나, 바다에 사는 너 — 일상어 입력 설계와 예상 질문 v1

> 2026-11-10 · 쏠 마을 관계 테스트 · 설계 초안(아직 켜지 않음)
> 지금 테스트는 38개 장면만 묻고 글 입력은 받지 않습니다. 나중에 일상어 입력을 받는다면 ① 무엇을 물을지 ② 어떤 글이 들어올지를 미리 정리했습니다.
> 문구 · 안전 처리 · 수치 목표는 모두 제안이며, CSO 확인 뒤에 반영합니다. 예시 문장은 전부 새로 쓴 합성 문장입니다(실제 사용자 글이 아닙니다).
> 같은 내용: `강에사는나_일상어입력_예상질문_v1.xlsx` · `worry_input.json`

## 먼저 읽을 다섯 가지

1. 첫 도입은 2부가 끝난 뒤(결과 기다림 앞) 자리에 두고, 입력 화면이 없는 비교군을 함께 둡니다. 타로의 8.2% 대 1.4%는 쓰는 사람이 원래 더 급한 효과가 섞여 있어 그대로 기대하기 어렵습니다.
2. 관계 테스트는 결정형 고민에 '어느 쪽'을 고르지 않습니다. 선택지 상자는 보여 주되 '정하기 전에 확인할 것'으로 바꿔 답합니다(이어 가라·끝내라 권유 금지 규칙과 같게).
3. 분류 성적은 세부 id가 아니라 '결과 틀'(읽어 준 문장 · 선택지 상자 · 답할 쪽 · 민감 표시)이 같은지로 봅니다.
4. 제3자({애칭})에 대한 글이 모이므로 개인정보처리방침 추가와 법률 검토가 끝난 뒤에 켭니다. 가장 조심스러운 첫걸음은 결제 뒤에만 받는 방식(D)입니다.
5. 썸 · 이별 · 기혼자 관계로 테스트하는 사람이 반드시 있습니다. 막지 않고 한 줄 안내와 민감 표시로 받습니다.

**숫자로 보면** 예상 질문 유형 35개(12묶음) · 예시 문장 210개 · 헷갈리는 짝 15쌍 · 기존 세부 고민 연결 22개 · 새로 필요한 세부 20개

**참고한 근거** 타로: 고민을 쓴 사람 결제 8.2% / 건너뛴 사람 1.4%, 81자 이상 17.0%, 짝사랑·썸 고민 13.3%, 자세한 예시가 긴 답을 늘림. 아스트로: 연애 고민 결제가 가장 높음, 거리두기 7.0% / 다가가기 3.5%, 결제의 93%가 60분 안.

**돌아가며 보이는 예시 6개** (3초마다 순환. 여섯 개 모두 '누구와 · 언제 · 무엇이 걸리는지'가 들어간 두 문장. 연애 4 · 결혼·동거 2. 온보딩에서 결혼·동거를 고른 사람에게는 3·6번을 먼저 보여 줌.)

1. 남자친구가 취업한 뒤로 평일엔 답장이 서너 시간씩 늦어요. 서운하다고 하면 부담 줄까 봐 괜찮은 척하게 돼요.
2. 지난 주말 약속 시간 문제로 다툰 뒤 사흘째 서로 연락을 안 하고 있어요. 이번에도 제가 먼저 연락해야 하는지 모르겠어요.
3. 결혼 3년 차인데 퇴근하면 각자 휴대폰만 봐요. 대화를 꺼내고 싶은데 뭐라고 시작해야 할지 모르겠어요.
4. 여자친구는 주말마다 만나고 싶어 하고, 저는 하루쯤 혼자 쉬고 싶어요. 말하면 서운해할까 봐 몇 달째 못 꺼냈어요.
5. 내년 봄에 전세 계약이 끝나는데, 같이 살자는 얘기를 누가 먼저 꺼낼지 서로 눈치만 보고 있어요.
6. 힘든 일이 있어도 남편은 '괜찮아'라고만 해요. 물어보면 더 말이 없어져서, 어디까지 물어봐도 되는지 모르겠어요.

- 안내문은 합쇼체, 예시는 사용자가 쓸 법한 말투(해요체)입니다.
- 건너뛰기 버튼은 제출 버튼과 같은 크기로 보여 줍니다. 글을 쓰지 않아도 결과는 같습니다.
- 각주의 '진단하지 않습니다' 문장과 보관 기간(비로그인 30일)은 기존 온보딩 문구와 같게 맞췄습니다.

### A-4. 결과 뒤 작은 질문 (선택)

**① 건너뛴 사람에게: "이 중 지금 가장 내 얘기 같은 문장은 무엇입니까?"**

- 자리: 3쪽 '지금까지 두 장이 보여 준 것' 아래, 멈추는 문단 위. 고민을 적지 않은 사람에게만 보임(적은 사람은 '읽어 준 한 문장'이 그 자리).
- 쓰임: 고른 문장을 4쪽 한 줄(p4_teaser)과 결제 상자 설명에 반영. 한 번 누르면 끝(글 입력 없음). 고르지 않아도 다음으로 넘어갈 수 있음.

| 잇는 역량 | 보기 문장 |
|---|---|
| 기대기 | 힘든 날에도 {애칭}에게 기대는 것이 어렵습니다. |
| 믿기 | 연락이 뜸하면 {애칭}의 마음이 달라진 건 아닌지 신경이 쓰입니다. |
| 선 지키기 | 싫은 것을 싫다고 말하지 못하고 맞춰 줄 때가 많습니다. |
| 말하기 | 서운한 일을 말로 꺼내기가 어렵습니다. |
| 회복하기 | 다툰 뒤 다시 편해지기까지 오래 걸립니다. |
| 미래 | 이 관계가 어디로 가는지 아직 확신이 서지 않습니다. |
| 없음 | 딱 맞는 문장이 없습니다. |

**② 결제한 사람에게: "리포트를 읽고 더 이야기하고 싶은 것이 있다면 적어 주세요."**

- 자리: 9쪽 실천 카드 아래 또는 10쪽 쏘웰라 안내 위
- 쓰임: 쏘웰라 첫 대화의 시작 문장으로 넘김. 결제자만 쓰므로 제3자 정보가 적게 모이고, 결과에 대한 질문(RQ-31~33)이 여기로 모임.

### A-5. 안전 처리 (제안 — CSO 결정 뒤 반영)

타로에서 이미 정한 방식(위기 → 안전 화면, 폭력 → 안내 상자, 두려움 → 안내 상자만)을 그대로 따르는 안입니다. 관계 테스트는 '폭력·간섭을 겪는 관계라면 관계성을 보는 것 자체가 맞지 않다'는 기존 원칙이 있어, 폭력·통제 글에는 다가가는 실천을 빼는 것을 더했습니다.

| 경우 | 찾는 방법 | 처리(제안) | 정할 것 |
|---|---|---|---|
| 위기 표현(삶을 끝내고 싶다는 뜻의 말) | 타로 safety_keywords의 urgent 목록 | 결과 대신 안전 화면을 먼저 보여 줌(자살예방상담전화 109 · 정신건강위기상담 1577-0199 · 위급하면 119). 결제 유도 없음. 타로 copy.safety.urgent_* 문구를 합쇼체로 옮겨 사용. | 타로 현행과 같음 |

### B-2. 유형별 상세

#### 연락·표현

**RQ-01 · 연락 횟수·답장 속도 차이**

- 정의: 사귀는 사이에서 연락 횟수나 답장 속도가 서로 달라 서운하거나 불안함. 연락 이야기가 글의 중심이고, 바쁜 환경 같은 이유는 드러나지 않음.
- 형태: 하소연(주) · 확인형(부) / 세부 고민: RL-CONTACT / 역량: 믿기 / 고리: 다가가기×거리두기(다가갈수록 멀어지는 사이), 다가가기×조율하기(빠른 쪽과 정리하는 쪽의 속도 차이)
- 3쪽 읽어 준 한 문장: **{이름}님은 {애칭}의 연락이 뜸해질 때 마음이 흔들리는 일을 적어 주셨습니다.** 연락을 기다리는 쪽과 늦게 답하는 쪽이 각자 어떤 방식으로 움직이는지, 두 사람의 결과로 풀어 보겠습니다.
- 답할 쪽: 5쪽 · 6쪽 · 8쪽 — 5쪽 흐름에서 '연락이 뜸해진 날' 장면을 쓰고, 6쪽 서운한 순간 첫 번째로 올림. 8쪽 '부탁할 말'에 연락에 대한 부탁 문장 한 줄.
- 민감 표시: 상대 마음 단정 금지
- 예시 문장(합성):
  - [타로식] 남자친구 연락이 점점 줄어드는데 마음이 식은 걸까요?
  - [타로식] 답장이 늦는 여자친구, 앞으로도 계속 이럴까요?
  - [하소연] 남친이 회사 들어간 뒤로 카톡 답이 서너 시간씩 걸려요. 무슨 일이 있는 것도 아니라는데 저만 기다리는 사람이 된 것 같아서 속상해요.
  - [하소연] 저는 틈틈이 연락하는 편인데 여자친구는 하루에 두세 번이 전부예요. 서운하다고 하면 부담 주는 사람처럼 보일까 봐 말을 못 하겠어요.
  - [반말·줄임말] 남친 읽씹 5시간째.. 나만 연락 기다리는 듯
  - [반말·줄임말] 여친이 연락 좀 자주 하래는데 난 원래 폰을 잘 안 봄 ㅠ 어케 맞춰야 됨

**RQ-02 · 애정 표현이 적음**

- 정의: 연락 횟수가 아니라 좋아한다는 말·칭찬·챙김 같은 표현이 적어서 사랑받는 느낌이 들지 않음.
- 형태: 하소연(주) · 방법형(부) / 세부 고민: RL-CONTACT, RL-TRUE / 역량: 말하기 / 고리: 맞춰주기×거리두기(말하지 않아 서로의 필요를 모르는 사이), 다가가기×거리두기(다가갈수록 멀어지는 사이)
- 3쪽 읽어 준 한 문장: **{이름}님은 {애칭}의 표현이 적어 마음이 허전해지는 순간을 적어 주셨습니다.** 표현의 크기가 다른 두 사람이 서로에게 어떻게 닿는지 살펴보겠습니다.
- 답할 쪽: 6쪽 · 7쪽 · 8쪽 — 6쪽에 '표현을 기다리다 허전해지는 순간'을 넣고, 7쪽에서는 {애칭}이 표현을 어려워할 수 있는 이유를 '~일 수 있습니다'로만 씀. 8쪽 부탁할 말에 '이럴 때 이렇게 말해 주면 좋겠어' 문장.
- 민감 표시: 상대 마음 단정 금지
- 예시 문장(합성):

  - [타로식] 무뚝뚝한 남편이 앞으로 조금은 달라질 수 있을까요?
  - [하소연] 사귄 지 1년이 넘었는데 좋아한다는 말을 들은 게 손에 꼽아요. 행동으로는 잘해 주는데도 가끔은 말로 듣고 싶어요.
  - [하소연] 생일에도 '축하해' 한마디가 끝이었어요. 큰 걸 바란 게 아닌데 저만 기념일을 챙기는 것 같아 허전해요.
  - [반말·줄임말] 여친이 사랑한단 말을 절대 먼저 안 함.. 나만 좋아하나
  - [반말·줄임말] 남편 표현 0임 ㅋㅋ 물어보면 꼭 말로 해야 아냐고 함

**RQ-03 · 서운한 걸 말로 못 꺼냄**

- 정의: 서운함이나 바라는 것이 있는데 분위기가 깨질까, 상대가 싫어할까 봐 말하지 못하고 삼킴. 걸리는 곳이 내 쪽의 말하기에 있음.
- 형태: 방법형(주) · 결정형(부) / 세부 고민: RL-SPEAK(새) / 역량: 말하기 / 고리: 맞춰주기×거리두기(말하지 않아 서로의 필요를 모르는 사이), 맞춰주기×조율하기(조용히 배려하지만 말하지 않은 기대가 쌓이는 사이)
- 3쪽 읽어 준 한 문장: **{이름}님은 {애칭}에게 꺼내지 못하고 삼킨 말이 있다고 적어 주셨습니다.** 그 말이 왜 입 밖으로 나오기 어려운지, 어떤 문장으로 시작할 수 있는지 결과에서 이어 보겠습니다.
- 선택지 상자: A: 지금 말해 본다 / B: 조금 더 지켜본다 — 말할지 말지를 정해 드리지 않습니다. 말한다면 어떤 한 문장으로 시작할지를 먼저 봅니다(8쪽 부탁할 말).
- 답할 쪽: 6쪽 · 8쪽 · 9쪽 — 6쪽에서 '괜찮다고 넘긴 순간'을 장면으로 쓰고, 8쪽 부탁할 말과 9쪽 실천 카드(한 문장 건네기)로 이어 줌.
- 민감 표시: 없음
- 예시 문장(합성):
  - [타로식] 서운한 걸 말하면 사이가 나빠질까요, 좋아질까요?
  - [타로식] 남자친구에게 속마음을 털어놓아도 괜찮을까요?
  - [하소연] 서운한 게 쌓였는데 막상 얼굴 보면 괜찮다고 해 버려요. 말하면 싸움이 될 것 같아서 매번 넘어가는데 속은 점점 답답해져요.
  - [하소연] 여자친구한테 바라는 게 있는데 어떻게 말해야 기분 상하지 않게 전할 수 있을지 모르겠어요. 말을 고르다 보면 타이밍이 지나가 있어요.
  - [반말·줄임말] 서운한데 말하면 예민하다 할까봐 걍 참는 중
  - [반말·줄임말] 할 말은 많은데 막상 만나면 입이 안 떨어짐 ㅠ

**RQ-04 · 힘든 걸 나누지 않음·기대기 어려움**

- 정의: 나 또는 상대가 힘든 일을 혼자 해결하고 기대지 않아서 거리감이나 서운함이 생김.
- 형태: 하소연(주) · 방법형(부) / 세부 고민: RL-LEAN(새) / 역량: 기대기 / 고리: 맞춰주기×거리두기(말하지 않아 서로의 필요를 모르는 사이), 거리두기×거리두기(조용하지만 멀어진 사이 (안내 문구 함께))

- 예시 문장(합성):

  - [하소연] 남자친구가 회사에서 안 좋은 일이 있었던 것 같은데 물어보면 별일 아니라고만 해요. 저는 옆에 있어도 도움이 안 되는 사람 같아요.

  - [반말·줄임말] 남친 힘든 거 다 티 나는데 물어보면 괜찮대. 난 뭐임
  - [반말·줄임말] 기대고 싶은데 짐 될까봐 말 못 하겠음

#### 다툼·화해

**RQ-05 · 같은 문제로 되풀이되는 다툼**

- 정의: 약속·말투·연락처럼 같은 주제로 다툼이 되풀이되어 지침. 다툼의 패턴 자체가 글의 중심임.

- 3쪽 읽어 준 한 문장: **{이름}님은 {애칭|과} 같은 문제로 다툼이 되풀이되는 일을 적어 주셨습니다.** 누구의 탓인지가 아니라, 두 사람의 방식이 어디서 맞물려 같은 자리로 돌아오는지 보겠습니다.
- 답할 쪽: 5쪽 · 8쪽 · 9쪽 — 5쪽 '부딪힌 뒤' 장면을 사용자가 적은 주제(약속·말투 등)로 구체화. 8쪽 함께 정할 약속에 고리의 '다리 놓기'를 연결.

  - [하소연] 싸울 때마다 저는 그 자리에서 풀고 싶고 남편은 나중에 얘기하자고 해요. 그러다 보니 싸움의 주제보다 싸우는 방식 때문에 더 크게 싸워요.

  - [반말·줄임말] 싸움 레퍼토리가 항상 같음 ㅋㅋ 고쳐지긴 하나

**RQ-06 · 다툰 뒤 말이 끊김·누가 먼저**

- 정의: 다툰 뒤 연락이 끊기거나 서로 말을 하지 않는 상태가 이어짐. 먼저 손 내밀지, 기다릴지가 중심임.
- 형태: 결정형(주) · 예측형(부) / 세부 고민: RL-COLD(새) / 역량: 회복하기 / 고리: 다가가기×거리두기(다가갈수록 멀어지는 사이), 거리두기×거리두기(조용하지만 멀어진 사이 (안내 문구 함께))
- 3쪽 읽어 준 한 문장: **{이름}님은 다툰 뒤 {애칭|과} 말이 끊긴 지금을 적어 주셨습니다.** 먼저 연락할지 기다릴지의 답보다, 두 사람이 다툰 뒤 각자 어떻게 마음을 가라앉히는지부터 보겠습니다.
- 선택지 상자: A: 먼저 연락한다 / B: 조금 더 기다린다 — 어느 쪽이 맞는지 정해 드리지 않습니다. 연락한다면 어떤 첫 문장이 덜 부담스러운지, 기다린다면 언제까지 기다릴지를 먼저 정해 봅니다(8쪽).
- 답할 쪽: 4쪽 · 5쪽 · 8쪽 — 4쪽 결제 뒤 '다리 놓기'가 가장 직접 닿는 유형. 5쪽 끝맺음 단계(하루가 지나감)를 사용자의 지금 상황으로 읽어 줌.
- 민감 표시: 예측 금지 · 상대 마음 단정 금지
- 예시 문장(합성):
  - [타로식] 싸우고 사흘째 연락이 없는데 먼저 연락이 올까요?
  - [타로식] 다툰 뒤 제가 먼저 연락하는 게 좋을까요, 기다리는 게 좋을까요?
  - [하소연] 지난주에 크게 싸운 뒤로 서로 연락을 안 하고 있어요. 늘 제가 먼저 풀었는데 이번엔 저도 지쳐서 손이 안 가요.
  - [하소연] 아내랑 말다툼한 뒤로 이틀째 집에서 필요한 말만 해요. 먼저 말을 걸고 싶은데 또 싸움이 될까 봐 눈치만 보고 있어요.
  - [반말·줄임말] 싸우고 3일째 잠수. 내가 먼저 해야 됨?
  - [반말·줄임말] 이번엔 진짜 먼저 연락 안 할 건데 불안함 ㅠ

**RQ-07 · 내 잘못 뒤 사과·회복**

- 정의: 말실수나 약속 어김처럼 내가 잘못한 일이 분명하고, 어떻게 사과하고 회복할지가 중심임.

- 3쪽 읽어 준 한 문장: **{이름}님은 {애칭}에게 미안한 일을 어떻게 풀어야 할지 적어 주셨습니다.** 사과가 닿는 방식은 사람마다 다르기에, 다툰 뒤 {애칭|이} 보이는 모습부터 함께 보겠습니다.
- 답할 쪽: 7쪽 · 8쪽 · 9쪽 — 7쪽({애칭}이 서운한 순간)을 앞세우고, 8쪽 '내가 바꿔 볼 것'에 사과 문장의 모양(무엇이 미안한지 한 가지 + 앞으로 할 한 가지)을 넣음.
- 민감 표시: 예측 금지 · 상대 마음 단정 금지
- 예시 문장(합성):

  - [타로식] 여자친구에게 사과하면 예전처럼 돌아갈 수 있을까요?
  - [하소연] 홧김에 해서는 안 될 말을 해 버렸어요. 사과는 했는데 그 뒤로 남자친구 말수가 눈에 띄게 줄어서 어떻게 해야 할지 모르겠어요.
  - [하소연] 기념일을 까맣게 잊어버렸어요. 미안하다고 여러 번 말했는데 아내는 괜찮다고만 하고 표정은 그대로예요.
  - [반말·줄임말] 내가 잘못한 거 맞는데 사과를 어케 해야 풀릴지 모르겠음
  - [반말·줄임말] 여친 생일 까먹음.. 망했다 어떡함

**RQ-08 · 말투·화내는 방식에 상처**

- 정의: 다툼의 주제보다 비꼬는 말투, 높아지는 언성, 한숨처럼 말이 나오는 방식에 상처받음. 욕설을 퍼붓거나 위협하거나 물건을 던지는 일은 이 유형이 아니라 RQ-34(안전)로 보냄.
- 형태: 하소연(주) · 방법형(부) / 세부 고민: RL-TONE(새) / 역량: 말하기 / 고리: 다가가기×다가가기(서로 먼저 맞서는 사이), 다가가기×맞춰주기(한쪽이 더 맞춰주는 사이)
- 3쪽 읽어 준 한 문장: **{이름}님은 {애칭|과} 다툴 때 오가는 말에 마음이 다친 일을 적어 주셨습니다.** 말의 내용보다 말이 나오는 방식이 두 사람 사이에서 어떻게 작용하는지 보겠습니다.
- 답할 쪽: 6쪽 · 8쪽 — 6쪽에 '그 말투를 들은 순간'을 장면으로, 8쪽 함께 정할 약속에 '말이 커지기 전 멈춤 신호'를 연결.
- 민감 표시: 폭력·통제 확인
- 예시 문장(합성):
  - [타로식] 화나면 말이 거칠어지는 남자친구, 고쳐질 수 있을까요?
  - [타로식] 제 말투 때문에 자꾸 싸우게 되는데 나아질 수 있을까요?
  - [하소연] 남편은 화가 나면 비꼬는 말투로 바뀌어요. 내용은 별거 아닌데 그 말투를 들으면 저도 모르게 목소리가 커져요.
  - [하소연] 여자친구가 싸울 때마다 한숨을 크게 쉬고 '됐어'라고 해요. 그 한마디에 무시당하는 기분이 들어서 더 따지게 돼요.
  - [반말·줄임말] 남친 싸울 때 말을 너무 세게 함. 상처받음
  - [반말·줄임말] 나 화나면 말이 막 나가는데 고치고 싶음 ㅠ

#### 거리·혼자 시간

**RQ-09 · 혼자 시간·만남 횟수 차이**

- 정의: 함께 있고 싶은 정도와 혼자 있고 싶은 정도가 달라 서운함이나 부담이 생김. 만남 횟수, 주말, 취미 시간이 소재임.
- 형태: 방법형(주) · 하소연(부) / 세부 고민: RL-SPACE(새) / 역량: 선 지키기 / 고리: 다가가기×거리두기(다가갈수록 멀어지는 사이), 다가가기×조율하기(빠른 쪽과 정리하는 쪽의 속도 차이)
- 3쪽 읽어 준 한 문장: **{이름}님은 함께하는 시간과 혼자 있는 시간의 차이를 적어 주셨습니다.** 가까이 있고 싶은 마음과 혼자 쉬고 싶은 마음이 두 사람 사이에서 어떻게 엇갈리는지 보겠습니다.
- 답할 쪽: 5쪽 · 6쪽 · 8쪽 — 5쪽 일상 장면(주말 약속)을 사용. 8쪽에서 혼자 시간을 '거절'이 아니라 '충전'으로 설명하는 부탁 문장을 줌. 어느 쪽 바람이 더 옳다고 쓰지 않음.
- 민감 표시: 상대 마음 단정 금지
- 예시 문장(합성):
  - [타로식] 혼자만의 시간이 필요하다는 남자친구, 마음이 식은 건 아닐까요?
  - [타로식] 자주 만나자는 여자친구와 제가 잘 맞춰 갈 수 있을까요?
  - [하소연] 저는 주말 하루는 집에서 혼자 쉬어야 충전이 되는데 남자친구는 이틀 다 같이 있고 싶어 해요. 쉬고 싶다고 하면 서운해해서 말을 꺼내기가 어려워요.
  - [하소연] 남편이 퇴근하면 방에 들어가 게임만 해요. 혼자 쉬는 시간이 필요한 건 알겠는데 저는 하루 종일 그 시간을 기다렸거든요.
  - [반말·줄임말] 여친은 맨날 보자는데 난 혼자 있는 시간도 필요함
  - [반말·줄임말] 남친이 주말에 자기 시간 갖겠대.. 서운한 내가 이상한 건가

**RQ-10 · 시간을 갖자고 한 상태**

- 정의: 한쪽이 '시간을 갖자'고 했거나 연락을 줄이며 거리를 두는 중임. 헤어진 것은 아님.
- 형태: 예측형(주) · 확인형(부) / 세부 고민: RL-BREAK / 역량: 믿기 / 고리: 다가가기×거리두기(다가갈수록 멀어지는 사이), 거리두기×조율하기(각자 정리하느라 연결 시간이 부족한 사이)
- 3쪽 읽어 준 한 문장: **{이름}님은 {애칭|과} 잠시 거리를 두게 된 지금을 적어 주셨습니다.** {애칭}의 마음을 대신 말할 수는 없지만, 거리가 생겼을 때 두 사람이 각자 어떻게 움직이는지는 결과로 볼 수 있습니다.
- 답할 쪽: 5쪽 · 6쪽 · 8쪽 — 5쪽에서 '거리가 생기면 나는 ~, {애칭}은 ~' 흐름을 읽어 줌. 기다리는 동안 나를 돌보는 실천을 9쪽에 우선 배치. 돌아온다·끝났다 어느 쪽도 암시하지 않음.
- 민감 표시: 예측 금지 · 상대 마음 단정 금지 · 이별 권유 금지
- 예시 문장(합성):
  - [타로식] 시간을 갖자던 남자친구가 다시 돌아올까요?
  - [타로식] 생각할 시간을 달라는 여자친구, 헤어지자는 뜻일까요?
  - [하소연] 남자친구가 요즘 너무 지친다며 당분간 연락을 줄이자고 했어요. 알겠다고는 했는데 기다리는 하루하루가 너무 길어요.
  - [하소연] 제가 먼저 시간을 갖자고 했어요. 싫어진 건 아니고 숨이 좀 막혀서 그런 건데 여자친구는 이별 통보로 받아들인 것 같아요.
  - [반말·줄임말] 시간 갖자는 말 = 헤어지자는 거임?
  - [반말·줄임말] 2주만 시간 달래서 기다리는 중인데 미치겠음

**RQ-11 · 바쁜 시기·장거리**

- 정의: 취업, 수험, 야근, 군 복무, 장거리처럼 환경 때문에 만남과 연락이 줄어든 시기. 한쪽이 기다리는 사람이 됨.
- 형태: 하소연(주) · 예측형(부) / 세부 고민: RL-BUSY(새) / 역량: 믿기 / 고리: 다가가기×조율하기(빠른 쪽과 정리하는 쪽의 속도 차이), 맞춰주기×거리두기(말하지 않아 서로의 필요를 모르는 사이)
- 3쪽 읽어 준 한 문장: **{이름}님은 바쁜 시기를 지나며 {애칭|과} 멀어진 느낌을 적어 주셨습니다.** 환경이 바뀔 때 두 사람이 각자 어떤 방식으로 버티는지 결과에서 이어 보겠습니다.
- 답할 쪽: 5쪽 · 6쪽 · 9쪽 — 쏠 마을 주인공 커플(시험 준비 중인 쪽과 신입사원인 쪽)과 가장 가까운 유형. 5쪽 장면을 '평일 저녁·주말' 기준으로 쓰고, 9쪽에 짧은 연결 실천(하루 한 줄 안부 등)을 둠.
- 민감 표시: 예측 금지
- 예시 문장(합성):
  - [타로식] 장거리 연애 중인데 저희가 끝까지 갈 수 있을까요?
  - [타로식] 남자친구가 취업 준비로 바쁜데 이 시기를 잘 넘길 수 있을까요?
  - [하소연] 남자친구가 신입사원이 된 뒤로 평일엔 거의 못 보고 주말엔 피곤해해요. 저는 아직 시험 준비 중이라 저만 제자리에서 기다리는 기분이에요.
  - [하소연] 여자친구가 다른 지역으로 발령이 나서 한 달에 두 번 봐요. 통화할 때마다 피곤해하는 목소리를 들으면 하고 싶은 말을 삼키게 돼요.
  - [반말·줄임말] 남친 야근 지옥이라 2주째 못 봄. 이해는 하는데 외로움
  - [반말·줄임말] 롱디 6개월차.. 점점 할 말이 없어짐

**RQ-12 · 나만 맞춰 줌·거절하지 못함**

- 정의: 메뉴, 일정, 부탁에서 늘 내가 맞추고 싫다는 말을 하지 못해 지침. 걸리는 곳이 내 선을 지키는 일에 있음.
- 형태: 하소연(주) · 방법형(부) / 세부 고민: RL-YIELD(새) / 역량: 선 지키기 / 고리: 다가가기×맞춰주기(한쪽이 더 맞춰주는 사이), 맞춰주기×맞춰주기(서로 눈치 보며 얽힌 사이)
- 3쪽 읽어 준 한 문장: **{이름}님은 {애칭}에게 맞추느라 내 마음이 뒤로 밀리는 일을 적어 주셨습니다.** 맞춰 주는 마음이 무엇을 지키려던 것인지, 어디서부터 내 바람을 말해 볼 수 있을지 보겠습니다.
- 답할 쪽: 6쪽 · 8쪽 · 9쪽 — 6쪽에 '다 괜찮다고 한 뒤 집에 와서 지친 순간'을 쓰고, 9쪽 실천에 작은 선택 하나(메뉴 고르기)를 둠. 거절하면 위협·보복이 따른다는 말이 있으면 RQ-34로.
- 민감 표시: 폭력·통제 확인
- 예시 문장(합성):
  - [타로식] 늘 제가 맞춰 주는 연애, 계속해도 괜찮을까요?
  - [타로식] 싫다고 말하면 남자친구가 저를 떠나지 않을까요?
  - [하소연] 데이트 장소도 메뉴도 늘 남자친구가 원하는 대로 해요. 저는 다 괜찮다고 하는데 집에 오면 이상하게 진이 빠져요.
  - [하소연] 여자친구 부탁은 웬만하면 다 들어주는 편이에요. 그런데 요즘은 거절하면 안 될 것 같은 기분이 들어서 제가 뭘 원하는지도 잘 모르겠어요.
  - [반말·줄임말] 맨날 내가 맞춰줌. 싫단 말을 못 하겠음
  - [반말·줄임말] 남친이 하자는 대로만 하다 보니 현타 옴

#### 신뢰·확인

**RQ-13 · 진심·사랑을 확인하고 싶음**

- 정의: 연락이나 표현 같은 구체적인 사건 없이, {애칭}이 나를 정말 좋아하는지, 믿어도 되는지가 불안함.
- 형태: 확인형(주) · 예측형(부) / 세부 고민: RL-TRUE / 역량: 믿기 / 고리: 다가가기×거리두기(다가갈수록 멀어지는 사이), 다가가기×맞춰주기(한쪽이 더 맞춰주는 사이)
- 3쪽 읽어 준 한 문장: **{이름}님은 {애칭}의 마음을 확인하고 싶은 순간을 적어 주셨습니다.** {애칭}의 속마음은 이 결과가 대신 말할 수 없습니다. 다만 {이름}님이 어떤 순간에 믿음이 흔들리고, 무엇이 있으면 안심이 되는지는 함께 볼 수 있습니다.
- 답할 쪽: 6쪽 · 8쪽 — 6쪽을 '믿음이 흔들리는 순간' 중심으로. 8쪽에 확인하고 싶을 때 쓸 수 있는 부탁 문장. '사실 사랑해서 그렇습니다' 같은 단정 금지.
- 민감 표시: 상대 마음 단정 금지 · 예측 금지
- 예시 문장(합성):
  - [타로식] 남자친구가 저를 진심으로 사랑하는 걸까요?
  - [타로식] 여자친구의 마음이 예전 같지 않은 것 같아요. 제 착각일까요?
  - [하소연] 잘해 주긴 하는데 가끔 저 혼자만 좋아하는 것 같다는 생각이 들어요. 딱히 무슨 일이 있었던 건 아닌데 자꾸 확인하고 싶어져요.
  - [하소연] 남편이 저를 사랑해서 같이 사는 건지 그냥 익숙해서인지 모르겠어요. 물어보면 당연한 걸 왜 묻냐고 해서 더 못 묻겠어요.
  - [반말·줄임말] 나만 좋아하는 거 같음.. 얘 진심 맞나
  - [반말·줄임말] 남친이 날 진짜 좋아하는지 모르겠다

**RQ-14 · 질투·이성 친구·전 연인**

- 정의: 이성 친구, 직장 동료, 전 연인과의 연락 때문에 마음이 쓰임. 바람을 의심하는 단계는 아님(의심·증거가 있으면 RQ-15).
- 형태: 하소연(주) · 확인형(부) / 세부 고민: RL-JEALOUS(새) / 역량: 믿기 / 고리: 다가가기×거리두기(다가갈수록 멀어지는 사이), 다가가기×맞춰주기(한쪽이 더 맞춰주는 사이)
- 3쪽 읽어 준 한 문장: **{이름}님은 {애칭}의 주변 사람 때문에 마음이 쓰이는 일을 적어 주셨습니다.** 확인하는 방법 대신, 그 불편함을 어떤 말로 전할 수 있을지 결과에서 이어 보겠습니다.
- 답할 쪽: 6쪽 · 8쪽 — 8쪽 부탁할 말을 '나를 주어로 한 문장'으로. 휴대폰 확인·위치 공유·만남 제한을 해결책으로 쓰지 않음. 상대가 만남을 막거나 검사한다는 말이 있으면 RQ-34로.
- 민감 표시: 감시 권유 금지 · 폭력·통제 확인 · 상대 마음 단정 금지
- 예시 문장(합성):
  - [타로식] 남자친구의 여사친이 자꾸 신경 쓰이는데 제가 예민한 걸까요?
  - [타로식] 여자친구가 전 남자친구와 아직 연락하는데 괜찮은 걸까요?
  - [하소연] 남자친구가 회사 여자 동기랑 점심을 자주 먹어요. 아무 사이 아닌 걸 알면서도 그 얘기를 들으면 하루 종일 기분이 가라앉아요.
  - [하소연] 제가 친구들 모임에 다녀오면 여자친구가 한동안 말이 없어져요. 왜 그러냐고 물으면 아니라고만 해서 저도 점점 모임 얘기를 안 하게 돼요.
  - [반말·줄임말] 남친 여사친 왤케 많음.. 질투하는 내가 싫다
  - [반말·줄임말] 여친이 구남친 인스타 아직 팔로우 중임. 말해도 되나

**RQ-15 · 외도 의심·알게 됨**

- 정의: {애칭}이 다른 사람을 만나는 것 같다는 의심이 구체적이거나, 이미 알게 됨.
- 형태: 확인형(주) · 결정형(부) / 세부 고민: RL-CHEAT(새) / 역량: 믿기 / 고리: 다가가기×거리두기(다가갈수록 멀어지는 사이)
- 3쪽 읽어 준 한 문장: **{이름}님은 {애칭}에 대한 믿음이 크게 흔들린 일을 적어 주셨습니다.** 이 결과는 사실을 가려 드릴 수 없고, 어느 쪽으로 정하라고 말하지도 않습니다. 지금 {이름}님에게 무엇이 먼저 필요한지를 함께 보겠습니다.
- 선택지 상자: A: 이야기를 꺼낸다 / B: 조금 더 지켜본다 — 휴대폰을 보거나 뒤를 따라가는 방법은 권하지 않습니다. 정하기 전에 내가 알고 싶은 것과 내가 받아들일 수 있는 선을 먼저 적어 봅니다(8쪽 · 쏘웰라).
- 답할 쪽: 6쪽 · 8쪽 · 10쪽 — 결과는 사실 여부를 판단하지 않음. 9쪽 실천은 나를 돌보는 것 위주로 고르고, 취약성을 드러내며 다가가는 실천은 뒤로 둠. 10쪽 쏘웰라로 이어 줌.
- 민감 표시: 외도 · 이별 권유 금지 · 감시 권유 금지 · 상대 마음 단정 금지
- 예시 문장(합성):
  - [타로식] 남자친구에게 다른 사람이 생긴 걸까요?
  - [타로식] 남편이 바람을 피우는 것 같은데 제 느낌이 맞을까요?
  - [하소연] 요즘 남자친구가 휴대폰을 엎어 두고 약속도 자주 바꿔요. 의심하는 제가 나쁜 사람 같다가도 불안해서 잠이 안 와요.
  - [하소연] 아내가 다른 사람과 주고받은 메시지를 우연히 보게 됐어요. 모른 척해야 할지 물어봐야 할지 며칠째 아무것도 못 하고 있어요.
  - [반말·줄임말] 남친 바람 피는 거 같음. 촉이 옴
  - [반말·줄임말] 여친 폰에 모르는 남자 이름 뜸.. 물어봐야 되나

#### 미래·결혼

**RQ-16 · 이 사람과 결혼해도 될지**

- 정의: 사귀는 사람과 결혼을 정할지 고민함. 확신이 부족하거나 마음에 걸리는 점이 있음.
- 형태: 결정형(주) · 예측형(부) / 세부 고민: MR-THIS, MR-WHETHER / 역량: 믿기 / 고리: 결과의 고리 그대로
- 3쪽 읽어 준 한 문장: **{이름}님은 {애칭|과} 결혼을 정하는 일을 적어 주셨습니다.** 이 결과는 결혼을 권하거나 말리지 않습니다. 대신 두 사람이 부딪혔을 때 어떻게 흘러가고 어떻게 다시 만나는지를 보여 드립니다.
- 선택지 상자: A: 결혼을 정한다 / B: 더 지켜본다 — 결과는 어느 쪽도 고르지 않습니다. 정하기 전에 둘이 먼저 이야기해 볼 주제(다툰 뒤 푸는 방식 · 돈 · 가족 · 혼자 시간)를 확인합니다(8쪽 함께 정할 약속).
- 답할 쪽: 5쪽 · 8쪽 — 고리는 사용자의 결과 그대로 씀. 8쪽 '함께 정할 약속'을 결혼 전 대화 주제로 읽어 줌. '잘 삽니다·안 맞습니다' 판정 금지.
- 민감 표시: 이별 권유 금지 · 예측 금지
- 예시 문장(합성):

- 형태: 확인형(주) · 방법형(부) / 세부 고민: TQ-REAL(새) / 역량: 해당 없음 / 고리: 결과의 고리 그대로
- 3쪽 읽어 준 한 문장: **{이름}님은 이 결과가 {애칭}의 실제 모습과 맞는지 궁금하다고 적어 주셨습니다.** 2쪽은 {이름}님의 눈에 비친 {애칭}의 모습입니다. {애칭|이} 직접 답하면 다르게 나올 수 있고, 그 차이가 두 사람이 나눌 이야기의 시작이 됩니다.
- 답할 쪽: 2쪽 · 7쪽 — AI 없이 고정 답변으로 처리(2쪽 아래 한 줄 + 고지문). 결과 뒤 작은 질문·쏘웰라·문의에서 더 자주 들어올 유형. 결제 상자는 기본 문구.
- 민감 표시: 상대 마음 단정 금지
- 예시 문장(합성):

  - [타로식] 상대가 직접 하지 않아도 결과를 믿을 수 있나요?
  - [하소연] 남자친구에 대한 질문에 '잘 모르겠어요'를 많이 골랐어요. 3년을 만났는데도 모르는 게 이렇게 많다는 게 좀 충격이에요.

**RQ-32 · 우리 궁합 괜찮은 건가요**

- 정의: 구체적인 사건 없이 두 사람이 잘 맞는지 판정을 듣고 싶어 함. 궁합, 상성, 점수.
- 형태: 확인형(주) · 예측형(부) / 세부 고민: TQ-MATCH(새) / 역량: 결과의 주 고민 역량 / 고리: 결과의 고리 그대로
- 3쪽 읽어 준 한 문장: **{이름}님은 {애칭|과} 잘 맞는 사이인지 궁금하다고 적어 주셨습니다.** 이 테스트는 맞는 짝과 안 맞는 짝을 가르지 않습니다. 어떤 조합이든 엇갈리는 곳과 만나는 곳이 함께 있고, 결과는 그 두 곳을 보여 드립니다.
- 답할 쪽: 3쪽 · 4쪽 · 5쪽 — 사전 입력에서 가장 많이 들어올 가벼운 유형으로 예상. 점수·등급·'상극' 표현 금지. 3쪽 '우리 사이 두 줄'과 4쪽이 답할 자리.
- 민감 표시: 예측 금지 · 이별 권유 금지
- 예시 문장(합성):

  - [타로식] 성격이 정반대인데 잘 맞는 커플이 될 수 있을까요?
  - [하소연] 딱히 고민이 있는 건 아니고 저희가 잘 맞는 사이인지 궁금해서 해 봐요. 친구들은 잘 어울린다는데 저는 가끔 너무 다르다고 느껴요.
  - [하소연] 다른 성격 테스트에서는 안 맞는다고 나오는데 실제로는 잘 지내고 있어요. 여기서는 어떻게 나올지 궁금해요.
  - [반말·줄임말] 우리 궁합 몇 점임?
  - [반말·줄임말] 남친이랑 잘 맞는지 걍 궁금해서 함 ㅋㅋ

**RQ-33 · 결과를 같이 봐도·보여 줘도 되나요**

- 정의: 결과를 {애칭}에게 공유하거나 같이 테스트해도 되는지, {애칭}이 기분 나빠하지 않을지를 물음.
- 형태: 결정형(주) · 방법형(부) / 세부 고민: TQ-SHARE(새) / 역량: 말하기 / 고리: 결과의 고리 그대로
- 3쪽 읽어 준 한 문장: **{이름}님은 이 결과를 {애칭|과} 함께 봐도 될지 궁금하다고 적어 주셨습니다.** 공유 카드에는 그림과 한 줄만 담기고, 답한 내용과 {애칭}에 대한 점수는 담기지 않습니다. 건넬 때 덧붙이면 좋은 한마디도 함께 안내해 드립니다.
- 선택지 상자: A: 결과를 보여 준다 / B: 혼자 간직한다 — 보여 줄지는 {이름}님이 정합니다. 보여 준다면 "내 눈에 비친 모습이라 틀릴 수 있어. 네가 보는 우리도 궁금해"처럼 여는 말을 권합니다.
- 답할 쪽: 4쪽 · 8쪽 — 고정 답변으로 처리. 공유 시트 안내(share.sheet_note)와 같은 내용을 3쪽에서 미리 알려 줌. RQ-28·34·35에는 공유를 권하지 않음.
- 민감 표시: 없음
- 예시 문장(합성):

  - [타로식] 여자친구와 같이 해 보면 사이가 더 좋아질까요?
  - [하소연] 결과를 남자친구한테 보내고 싶은데 자기를 평가했다고 기분 나빠할까 봐 걱정돼요. 어떻게 말하면서 보내야 할지 모르겠어요.
  - [하소연] 남편한테 같이 해 보자고 하고 싶은데 이런 걸 안 좋아하는 사람이라 말을 꺼내기가 조심스러워요.

> 타로의 '고민을 쓴 사람 8.2% vs 건너뛴 사람 1.4%'는 원래 마음이 급한 사람이 글도 쓰고 결제도 하는 효과가 섞인 숫자. 입력 화면 자체의 효과를 보려면 입력 화면이 없는 비교군이 꼭 필요함.
