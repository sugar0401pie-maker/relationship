# 강에 사는 나, 바다에 사는 너 — 쏠 마을 관계 테스트 — 디자인 가이드

로고 파일: `logo_navy_on_white.png`(흰 배경 버전), `logo_cream_on_navy.png`(남색 배경 버전)

## 디자인 가이드 — 쏠 웰니스 하우스 로고 색감 우선

화면·결과 카드·공유 이미지·리포트 등 디자인을 구성할 때는 **되도록 쏠 웰니스 하우스 로고(물결 심볼)에 쓰인 색감을 활용한다.** 디저트 테스트의 핑크·피치 팔레트는 이 테스트에 쓰지 않는다. 로고는 두 가지 버전이 있다: 흰 배경 위 남색 물결, 남색 배경 위 크림색 물결.

| 토큰 | 값 | 출처 | 쓰는 곳 |
|---|---|---|---|
| `--navy` | `#013566` | 로고 (흰 배경 버전) | 포인트 색: 버튼, 유형 이름, 큰 제목, 선택된 보기, 레이더의 "나" |
| `--navy-deep` | `#01365C` | 로고 (남색 배경 버전) | 히어로·인트로 배경, 결제 카드, 하단 고정 바 |
| `--cream` | `#FDF6E9` | 로고 (크림 물결) | 페이지 배경, 남색 배경 위 글자·로고 |
| `--white` | `#FFFFFF` | 로고 (흰 배경 버전) | 카드 배경 |
| `--sky` | `#C9D9E8` | 남색에서 파생 (채도 낮은 하늘색) | 보조 배경, 레이더의 "{애칭}", 비활성 칩 |
| `--sky-soft` | `#EEF3F8` | 파생 | 섹션 구분 배경, 블러 구간 배경 |
| `--ink` | `#1C2B3A` | 파생 | 본문 텍스트 (남색은 본문에 쓰지 않고 포인트에만) |
| `--line` | `#D8E1EA` | 파생 | 테두리, 구분선 |

- 기본 조합: 크림 배경 + 흰 카드 + 남색 포인트. 강조 화면(인트로, 결제 카드, 히든 유형 공개)은 남색 배경 + 크림 글자로 로고의 반전 버전과 맞춘다.
- 물결 심볼은 섹션 구분선, 로딩 표시("리포트 만드는 중"), 공유 카드 하단 워터마크에 활용할 수 있다.
- 캐릭터 일러스트는 원래 색을 유지하고, 그 주변 UI(배경·버튼·텍스트)만 로고 색감으로 맞춘다.
- 대비: 남색과 크림, 남색과 흰색 조합은 본문용으로 충분히 진하다. 하늘색(`--sky`) 위에는 남색이나 `--ink` 글자만 쓴다.
- 폰트·모서리·버튼 형태 같은 나머지 디자인 시스템은 디저트 테스트 Next.js 스펙을 따르되, 색상 변수만 위 값으로 바꾼다.
- 이 색감은 쏠 웰니스 하우스 브랜드 기준(남색·채도 낮은 하늘색·흰색)과 같은 방향이다.
