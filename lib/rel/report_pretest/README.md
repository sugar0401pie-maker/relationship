# AI 리포트 사전 테스트 (출시 전 점검용)

예시 리포트 10개와 같은 조합의 가상 응답 10건으로 실제 AI 리포트(4번 본문~8번)를 만들어 보고, `리포트_AI프롬프트.md` §4의 자동 검증 9개 규칙과 추가 규칙 2개(X1·X2)로 채점하는 도구입니다. Node 20 이상에서 돌아가고, 따로 설치할 패키지는 없습니다.

| 파일 | 역할 |
|---|---|
| `build_input.mjs` | 케이스 → `{system, user}` 조립. 시스템 프롬프트 §3 전문, 입력 값 §2, 두 유형 base_knowledge, 같은 고리의 예시(`<style_example>`), 방향별 관계의 유료 5필드(`<pair_relation>`)를 넣음 |
| `cases.json` | 예시 리포트 10개의 입력 요약(유형·애칭·관계·엇갈림·저울·속·겉)과 맞춘 가상 응답. 채점은 `scoring.js`로 다시 계산함 |
| `validate.mjs` | 자동 검증(R1~R9 + X1·X2) |
| `run_pretest.mjs` | 실행 CLI |
| `selftest.mjs` | 검증기 자기 점검(사람이 쓴 예시 10개 + 망가뜨린 변형 B1~B4) → `out/sample_validation.md`. 예시 10개는 X2까지 모두 통과해야 하고, B4는 X2로 잡혀야 함 |

## 실행

```bash
cd 03_코드/report_pretest
node run_pretest.mjs --dry-run            # 프롬프트만 만듦(네트워크 없음) → out/caseNN.prompt.txt
export OPENAI_API_KEY=...                 # 키는 환경 변수로만. 파일·코드에 적지 마세요
node run_pretest.mjs                      # 10건 모두 생성
node run_pretest.mjs --case 3             # 샘플 3번 조합만
node run_pretest.mjs --no-style           # 예시 리포트 없이(베끼는지 비교용)
node run_pretest.mjs --model gpt-6-sol    # 모델 지정(기본값 gpt-6-sol)
node selftest.mjs                         # 검증기 점검
```

운영과 같게 `incomplete`이면 1회 다시 부르고, 검증에 실패하면 1회 다시 생성합니다. 사전 테스트에서는 실패한 글도 `out/caseNN.md`로 저장해서 눈으로 볼 수 있게 했습니다(운영에서는 저장하지 않고 알림).

주의: 케이스의 예시 리포트가 바로 그 케이스의 `<style_example>`로 들어갑니다(고리마다 예시가 하나뿐이라서). 그래서 기본 실행은 베끼기 쉬운 조건입니다. `--no-style` 결과와 꼭 같이 보세요.

## 결과 읽는 법

- `out/summary.md` / `summary.csv`: 케이스마다 통과·실패, 규칙별 O/X, 공백 제외 글자 수, 지연(ms), 토큰(in/out), 생성 횟수(1 또는 2)
- `out/caseNN.md`: AI가 쓴 본문, `caseNN.validation.json`: 규칙별 상세와 호출 기록

| 규칙 | 내용 |
|---|---|
| R1 | `### 4.`~`### 8.` 제목 일치(6번은 애칭 조사 반영), 1~3번 헤더 없음 |
| R2 | 공백 제외 3,000~4,500자(헤더 포함) |
| R3 | 5·6·8번 `•` 줄 각 3개, 7번 `첫째,`·`둘째,`·`셋째,` 문단 |
| R4 | 8번 마지막 문단이 "이 리포트와 함께 1주일간 AI 채팅 이용권이 제공됩니다"로 시작 |
| R5 | 금지어(회피형·불안형·집착·이기적·최악·상극·헤어지·이별하·참아야·`**`) 없음 |
| R6 | 21유형 관련 이론의 학자 이름(로마자·한글 표기)과 영어 이론명 없음 |
| R7 | 따옴표 밖 해요체 0건(~세요·~까요? 제외), 한 섹션 안 같은 끝 표현 3문장 연속 없음 |
| R8 | 문단당 5문장 이하 |
| R9 | "고르셨" 3회 이상 |
| X1 | 방향별 관계 문장을 25자 이상 그대로 옮기지 않음 |
| X2 | 동물·캐릭터 비유와 물·바다 은유 없음: 21개 유형 이름(`relationship_test_data.json`의 `types[].name`) 바로 뒤 "처럼·같이·답게" 0건, 은유 단어(물밑·발장구·수면 위·껍데기·모래 속·파도에) 0건. CSO 검수(2026-10-22) 반영 |

## "통과"의 뜻

"통과"는 코드로 셀 수 있는 형식 규칙을 지켰다는 뜻일 뿐, 좋은 리포트라는 뜻은 아닙니다. 아래 항목은 사람이 읽고 판단해야 합니다.

- 말투와 결: 상담사처럼 따뜻하고 깊이 있는지, 합쇼체가 딱딱하지 않은지
- 애칭에 대한 판정: "내 눈에 비친"·"~해 보입니다"를 지켰는지, 속마음을 단정하거나 한쪽 편을 들지 않았는지, 상대가 읽어도 괜찮은지
- 장면의 질: 이 두 유형과 응답에 맞는 구체적 장면인지, 결혼·동거일 때 집·식사·집안일 장면으로 바뀌었는지, 예시 리포트를 베끼지 않았는지
- 근거 → 기제 → 장면 흐름, 7번의 "내가 / 부탁 / 함께" 균형, 관계를 이어가라·끝내라·참아라로 읽히는 문장이 없는지
